# Application Screenshots

This folder contains screenshots documenting the Inventory System application features and user interface.

## Screenshot descriptions

| File | Description |
|------|-------------|
| **login-page.png** | User login interface - form for entering credentials |
| **registerpage.png** | User registration interface - form for creating new account |
| **user-dashboard.png** | Dashboard view for regular users - shows product overview |
| **admin-products.png** | Admin product listing page - displays all products in a table/list format |
| **admid-add-products.png** | Admin product creation/edit form - interface for adding or modifying products |
| **swagger.png** | API documentation page via Swagger UI - shows available API endpoints |

## How to view

1. Navigate to the root project folder
2. Open any image file in this folder to preview
3. For API documentation, run the backend server and visit `http://localhost:3000/api/docs`
